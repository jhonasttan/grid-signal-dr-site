Grid Signal DR — Data Methodology & Public Source Provenance

Versioned Revision Tracking

All metrics in the Grid Signal DR pipeline are tracked via a revision_version column. The schema enforces UNIQUE(period_month, distributor, revision_version) for distribution_losses and UNIQUE(effective_month, tariff_category, revision_version) for tariff_components. During re-ingestion, a newly scraped metric with a higher revision_version supersedes the prior row, while the original historical row is retained. This ensures immutable audit trails and the ability to roll back to prior SEED baselines if needed.

Foreign-Key Citation Enforcement

SQLite PRAGMA foreign_keys = ON is set at connection time. Every row in distribution_losses and tariff_components references a valid source_id in regulatory_sources. The PRAGMA foreign_key_check command returns 0 violations on a clean dataset, guaranteeing that no metric exists without a cited source document.

Spanish-to-English Regulatory Normalization

All regulatory filings from the following Dominican Republic government portals are scraped, PDF-extracted via pdfplumber, and Excel-parsed via openpyxl, then normalized through a hybrid LLM pipeline (OpenRouter Free meta-llama/llama-3.3-70b-instruct:free → local Ollama qwen2.5:7b-instruct) with a strict 3-second TTFT timeout. The system prompt anchors the LLM to the Dominican Republic power market domain, ensuring every extracted metric maps to a cited source. Portals covered: SIE (sie.gob.do), Organismo Coordinador (oc.do), MEM (mem.gob.do), and CNE (cne.gob.do).
